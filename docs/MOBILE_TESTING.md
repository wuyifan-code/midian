# 移动端真机测试清单（Mobile Device Testing Checklist）

> 目标是覆盖所有 README「特性」条目。建议 Android 与 iOS 各跑一遍；优先测试你日常使用的 Provider。
> 每项完成后勾选并记录「机型 / 系统 / Obsidian 版本 / 日期」。
> 发现问题时：记录复现步骤，保留会话（`.midian/sessions/`），必要时导出对话。

## 准备

- [ ] 桌面端 `npm run build`，把 `main.js`、`manifest.json`、`styles.css`、`versions.json` 放入 Vault 的 `.obsidian/plugins/midian/`
- [ ] 通过 Obsidian Sync 同步到手机，或按 `docs/SIDELOADING.md` 手动复制
- [ ] 手机上启用插件，设置里填入 API Key 并通过「测试连接」

## 1. 基础与设置

- [ ] Ribbon 图标 / 命令面板「打开 Midian 聊天」打开全屏视图
- [ ] 未配置 Key 时欢迎页显示「打开设置」按钮且可跳转
- [ ] 设置页：Provider 切换、模型名、Max Tokens、Persona 修改后立即生效（重启不丢）
- [ ] API Key 输入框默认掩码显示，点眼睛图标可切换明文
- [ ] 设置页「测试连接」：正确 Key 返回成功；错误 Key 返回 HTTP 错误码

## 2. 流式输出

- [ ] Anthropic 官方端点：回复逐字流式出现，可随时点「停止」
- [ ] OpenAI 兼容端点（如 DeepSeek）：若端点不支持浏览器直连，自动降级为非流式，回复一次性出现且无报错
- [ ] 思考块（thinking / reasoning_content）正常显示并可折叠
- [ ] 流式中途停止：会话正常保存已生成部分，聊天不卡死
- [ ] 流式出错：显示错误行 + 「重试」按钮，点击后重新生成

## 3. 工具调用与批准

- [ ] 让 AI 读取笔记（`read_note`）：无需批准自动执行，卡片显示结果
- [ ] 让 AI 写/追加/改属性（写入类）：弹出批准卡片，含参数详情
- [ ] 批准卡片：允许 / 拒绝 / 「本次会话始终允许」都按预期工作
- [ ] 等待批准时点「停止」：卡片显示「已取消」，会话正常结束不卡死
- [ ] `ask_user` 提问卡片：预设选项可点、自由输入可提交，回答回到模型
- [ ] 工具结果错误（如路径不存在）在卡片中显示失败状态

## 4. 图片

- [ ] 从 Vault 选图片随消息发送（含纯图片消息），模型能描述图片内容
- [ ] 多轮对话：第二轮起模型仍记得第一轮的图片（历史图片重挂）
- [ ] 大于 5MB 的图片：提示「图片超过 5MB，已跳过」，不报错
- [ ] 图片 chip 可移除；消息发送后 chip 清空

## 5. 上下文

- [ ] 打开一篇笔记，发送消息时默认附带（可点输入框旁的按钮关闭）
- [ ] 编辑器选中文本时只发送选区
- [ ] `@` 提及：picker 搜索并附加笔记 chip，移除后不再进入上下文
- [ ] 长对话（>40 条消息）：自动裁剪历史，显示「较早的对话已省略」提示

## 6. 会话管理

- [ ] 新建 / 重命名（点头部标题）/ 删除 / 复制（fork）/ 回退（rewind）均正常
- [ ] 历史对话框：按标题 / 模型 / 消息内容搜索可命中
- [ ] 导出对话为笔记：生成 Markdown，含图片嵌入与思考块引用，可打开
- [ ] 编辑最后一条用户消息：取回输入框，改后重发，之后的历史被截断
- [ ] 首轮对话后自动生成标题（或保持默认标题）

## 7. 记忆引擎

- [ ] 开启记忆后聊完一轮，`.midian/memory/short-term.md` 出现要点
- [ ] 第二次对话中模型能引用此前记忆（注入画像）
- [ ] 记忆关闭时：不写入任何记忆文件
- [ ] 记忆提取失败（断网等）不影响聊天本身

## 8. 稳定性与恢复

- [ ] 飞行模式 / 断网时发送：出现友好错误，重连后重试成功
- [ ] 发送后立刻杀进程重开：会话与消息仍在
- [ ] 100+ 条消息的会话打开与滚动不卡顿
- [ ] 切换 Provider 后新会话使用新配置，旧会话保持原 Provider/模型
- [ ] 后台挂起（切 App 再回来）：输入框内容、流式状态不丢失或可恢复

## 9. 输入法 / 键盘（重点）

- [ ] 中文输入法联想选词（组合状态）按 Enter 不误发送（IME 安全）
- [ ] Enter 发送；Shift+Enter（桌面）换行
- [ ] 键盘弹出时输入框不被遮挡，安全区（底部横条）不遮挡发送按钮
- [ ] 斜杠菜单：输入 `/` 呼出，点选后模板插入

## 10. 代码块

- [ ] AI 输出代码块可一键复制；复制按钮在触摸屏上可用
